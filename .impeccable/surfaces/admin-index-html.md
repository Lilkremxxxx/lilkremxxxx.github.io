# Surface brief: admin (admin/index.html)

Mode: Operate. User: the owner only, desktop first, sometimes phone. Tasks: sign in; create/edit/publish/delete blog posts as content blocks with live preview; manage tags; edit every home-page section (EN + optional VN) with reset-to-default. Important states: signed out, loading, dirty/unsaved, saving, saved, error, empty, API down. Same world as the public site but restrained: glass panels over a static gradient (no WebGL), precision over expression. Never use native confirm/alert; destructive actions confirm inline.
